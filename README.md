# Maksim Kosmakov

Personal academic website: https://makosmakov.github.io/

Hosted by GitHub Pages from the root of the `main` branch.

To preview locally, run `python3 -m http.server 8000` and open http://localhost:8000.

Edit `index.html` for content and `styles.css` for styling. The portrait and downloadable CV are in `assets/`. Push changes to `main` to publish them.
